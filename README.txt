IIT (BHU) SUNNY ISLAND MAP

This website uses the edited IIT (BHU) reference map as the main visual.

Visual changes:
- Converted the night campus into a bright sunny tropical island.
- Removed the strong orange street-light appearance.
- Kept the road network visually clear.
- Reduced the dense-tree look compared with a full jungle/island illustration.
- Preserved the campus layout and recognizable landmark placement as much as possible.
- Added a subtle 3D/isometric camera feel.

Interaction:
- Move the mouse across the map for a gentle opposite-direction parallax.
- The map has a very small continuous floating motion.
- Moving the cursor around changes the camera tilt slightly.
- There are no extra panels, instructions, compass, or sidebars.

Open index.html in Chrome/Edge.
